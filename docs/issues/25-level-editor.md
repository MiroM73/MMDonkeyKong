# In-game level editor with test play and text export / import

Paint the ASCII grid of the level format on screen (mouse / touch), validate with the validator of issue 22, test play, export / import as text, store custom levels in the save, and list them in the level-select screen under 'My levels'.

## Done when
- Tests, fmt and clippy clean on Windows, Linux and wasm; behaviour checked in the running program; docs and roadmap updated; `t!` keys in all four `lang/*.lang`.

See `docs/game-design.md` and `docs/platforms.md`.
